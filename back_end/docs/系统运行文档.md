## 1. 系统概述

车辆维修管理系统是一个全栈Web应用，采用前后端分离架构，为汽车维修店提供完整的业务管理解决方案。

### 1.1 主要功能模块

- **用户管理**：支持客户、技师、管理员三种角色
- **车辆管理**：车辆信息登记和维护
- **工单管理**：维修工单的全流程管理
- **库存管理**：配件库存的实时管理
- **支付管理**：费用计算和支付状态跟踪
- **反馈系统**：客户评价和催单功能
- **数据报表**：业务数据统计和分析

### 1.2 系统架构

```
┌─────────────────┐    HTTP/HTTPS    ┌─────────────────┐
│   前端 (Vue 3)   │ ◄──────────────► │  后端 (Koa.js)  │
│   Port: 5173    │                  │   Port: 3000    │
└─────────────────┘                  └─────────────────┘
                                              │
                                              ▼
                                    ┌─────────────────┐
                                    │ 数据库 (MySQL)  │
                                    │   Port: 3306    │
                                    └─────────────────┘
```

## 4. 安装部署

### 4.1 克隆项目

```bash
# 克隆代码仓库
git clone <repository-url>
cd dbpj

# 查看项目结构
ls -la
# 应该看到 back_end/ 和 front_end/ 两个目录
```

### 4.2 数据库安装配置

#### 4.2.1 MySQL安装

**Windows:**
```bash
# 下载MySQL 8.0+ 安装包并安装
# 或使用包管理器
winget install Oracle.MySQL
```

**macOS:**
```bash
# 使用 Homebrew
brew install mysql

# 启动MySQL服务
brew services start mysql
```

**Ubuntu/Debian:**
```bash
# 更新包列表
sudo apt update

# 安装MySQL
sudo apt install mysql-server

# 启动并启用服务
sudo systemctl start mysql
sudo systemctl enable mysql
```

#### 4.2.2 数据库初始化

```bash
# 登录MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE vehicle_repair_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 创建用户（可选）
CREATE USER 'repair_user'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON vehicle_repair_system.* TO 'repair_user'@'localhost';
FLUSH PRIVILEGES;

# 退出MySQL
EXIT;
```

### 4.3 后端安装

```bash
# 进入后端目录
cd back_end

# 安装依赖
npm install

# 创建环境变量文件
node create-env-file.js
```

### 4.4 前端安装

```bash
# 进入前端目录
cd front_end

# 安装依赖
npm install
```

## 5. 配置说明

### 5.1 后端环境变量配置

编辑 `back_end/.env` 文件：

```bash
# 数据库配置
DB_HOST=localhost          # 数据库主机地址
DB_PORT=3306              # 数据库端口
DB_NAME=vehicle_repair_system  # 数据库名称
DB_USER=root              # 数据库用户名
DB_PASSWORD=123456        # 数据库密码

# 服务器配置
PORT=3000                 # 后端服务端口
NODE_ENV=development      # 运行环境: development/production

# JWT配置
JWT_SECRET=your-super-secret-jwt-key-here
JWT_REFRESH_SECRET=your-super-secret-refresh-key-here
JWT_EXPIRES_IN=24h        # 访问令牌过期时间
JWT_REFRESH_EXPIRES_IN=7d # 刷新令牌过期时间

# 日志配置
LOG_LEVEL=info           # 日志级别: error/warn/info/debug
LOG_FILE=logs/app.log    # 日志文件路径

# 文件上传配置
UPLOAD_DIR=uploads       # 上传文件目录
MAX_FILE_SIZE=10485760   # 最大文件大小 (10MB)

# 应用配置
APP_NAME=车辆维修管理系统
APP_VERSION=1.0.0
```

### 5.2 生产环境配置调整

```bash
# 生产环境配置示例
NODE_ENV=production
DB_HOST=your-production-db-host
DB_PASSWORD=your-strong-password
JWT_SECRET=your-production-jwt-secret-minimum-32-characters
LOG_LEVEL=warn
```

### 5.3 前端配置

如需修改后端API地址，编辑前端相关配置文件（通常在API客户端配置中）。

## 7. 功能使用

### 7.1 系统登录

#### 默认账号

系统初始化后提供以下默认账号：

| 角色 | 用户名 | 密码 | 说明 |
|------|--------|------|------|
| 管理员 | 系统管理员 | admin123456 | 系统管理员账号 |
| 客户 | 张三 | customer123 | 示例客户账号 |
| 技师 | 李师傅 | mechanic123 | 示例技师账号 |

#### 登录流程

1. 访问前端页面：http://localhost:5173
2. 输入用户名和密码
3. 点击登录
4. 系统验证成功后跳转到对应角色的主页

### 7.2 角色功能说明

#### 7.2.1 管理员功能

- 用户管理：查看、创建、编辑用户信息
- 技师管理：管理技师档案和工作分配
- 工单管理：查看所有工单，分配技师
- 库存管理：配件入库、出库、库存调整
- 财务管理：查看收支报表，处理支付
- 系统报表：各类业务统计报表

#### 7.2.2 客户功能

- 车辆管理：添加、编辑车辆信息
- 工单管理：创建维修工单，查看进度
- 费用支付：查看费用明细，完成支付
- 服务反馈：对完成的工单进行评价
- 催单功能：对进行中的工单进行催单

#### 7.2.3 技师功能

- 工单接收：查看分配的工单并接受
- 工作记录：记录工作时长和进度
- 材料申请：申请使用的配件材料
- 进度更新：更新工单完成状态

### 7.3 核心业务流程

#### 7.3.1 维修工单流程

```
客户创建工单 → 管理员分配技师 → 技师接受工单 
     ↓
技师开始维修 → 记录工作进度 → 申请使用配件 
     ↓
完成维修 → 系统计算费用 → 客户确认支付 → 客户评价
```

#### 7.3.2 库存管理流程

```
配件入库 → 库存记录 → 工单使用 → 自动扣减 
    ↓
库存预警 → 补充采购 → 入库登记 → 更新库存
```

## 8. API文档

### 8.1 访问API文档

- **在线文档**：http://localhost:3000/api/v1/docs
- **JSON格式**：http://localhost:3000/api/v1/docs/openapi.json

### 8.2 认证方式

系统使用JWT Bearer Token认证：

```bash
# 获取token
curl -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"name":"系统管理员","password":"admin123456"}'

# 使用token访问API
curl -X GET http://localhost:3000/api/v1/admin/users \
  -H "Authorization: Bearer <your-token>"
```

### 8.3 主要API端点

| 功能模块 | 端点 | 说明 |
|----------|------|------|
| 认证 | /api/v1/auth/* | 登录、注册、刷新token |
| 用户管理 | /api/v1/admin/users/* | 用户CRUD操作 |
| 车辆管理 | /api/v1/customers/vehicles/* | 车辆信息管理 |
| 工单管理 | /api/v1/customers/work-orders/* | 工单操作 |
| 库存管理 | /api/v1/admin/inventory/* | 库存管理 |
| 技师功能 | /api/v1/mechanic/* | 技师相关操作 |

## 9. 常见问题

### 9.1 安装问题

**Q: npm install 失败**
```bash
# 清理缓存并重新安装
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

**Q: MySQL连接失败**
```bash
# 检查MySQL服务状态
sudo systemctl status mysql  # Linux
brew services list | grep mysql  # macOS

# 检查端口是否被占用
netstat -an | grep 3306
```

### 9.2 启动问题

**Q: 端口被占用**
```bash
# 查找占用端口的进程
lsof -i :3000  # macOS/Linux
netstat -ano | findstr :3000  # Windows

# 修改端口配置
# 编辑 .env 文件中的 PORT 配置
```

**Q: 数据库连接超时**
```bash
# 检查数据库配置
# 确认 .env 文件中的数据库配置正确
# 检查MySQL服务是否正常运行
```

### 9.3 功能问题

**Q: 登录失败**
- 确认用户名密码正确
- 检查数据库是否已初始化
- 查看后端日志确认错误原因

**Q: 文件上传失败**
- 检查上传目录权限
- 确认文件大小未超过限制
- 查看服务器磁盘空间

### 9.4 性能问题

**Q: 接口响应慢**
- 检查数据库连接数
- 分析慢查询日志
- 考虑添加数据库索引

**Q: 前端加载慢**
- 使用生产构建版本
- 启用gzip压缩
- 考虑使用CDN
